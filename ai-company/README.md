# AI社長室（AI社員型 SNS・note 売上最適化システム）

## これは何のアプリ？

Instagram・TikTok・YouTube・note・lit.link・LINEのデータを、
「AI社員」たちが分析し、「AI社長」が

**「今日、一番やるべきことは何か」**

を毎日1つだけ教えてくれるアプリです。

最終ゴールは再生数やフォロワー数を増やすことではなく、
**noteの購入数・売上を増やすこと**です。

現在は **PHASE 1（Instagram接続）** の段階です。
「ダッシュボード」「AI社員一覧」の画面はまだPHASE 0のダミーデータのままですが、
「Instagram投稿一覧」画面だけは、あなた自身のInstagramアカウントに接続して
実際の投稿データを表示できるようになりました。

このアプリは2つの部分でできています。

- **フロントエンド**（画面）：`ai-company/prototype/` 。ブラウザで開く部分
- **バックエンド**（データを取りに行く裏方）：`ai-company/backend/` 。Instagramと通信してデータベースに保存する部分

Instagramのデータを見るには、両方を起動する必要があります。

## 起動方法

### 1. 画面（フロントエンド）を開く

1. パソコンでこのリポジトリを開きます
2. `ai-company/prototype/index.html` というファイルを見つけます
3. そのファイルを**ダブルクリック**して、ブラウザ（Chrome・Safariなど）で開きます

「ダッシュボード」「AI社員一覧」はこれだけで見られます（ダミーデータ）。

もしダブルクリックで開けない場合は、ターミナル（黒い画面）で次のコマンドを実行してください。

```
cd ai-company/prototype
python3 -m http.server 8000
```

実行後、ブラウザで `http://localhost:8000` を開きます。

### 2. データを取りに行くサーバー（バックエンド）を起動する

「Instagram投稿一覧」画面を実データで見るには、別のターミナルでこちらも起動します
（初回だけ準備作業があります。「API接続方法」を先に読んでください）。

```
cd ai-company/backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --port 8001
```

「Uvicorn running on http://127.0.0.1:8001」と表示されたら起動成功です。
このターミナルは**開いたまま**にしておいてください（閉じるとサーバーが止まります）。

## 終了方法

- 画面（ブラウザ）：タブを閉じるだけでOKです
- `python3 -m http.server` を使った場合：そのターミナルで `Ctrl + C`
- バックエンド（`uvicorn`）：そのターミナルで `Ctrl + C`

## 再起動方法

終了方法のあと、もう一度「起動方法」を実行してください。
2回目以降は `python3 -m venv .venv` は不要です（`source .venv/bin/activate` から）。

## API接続方法（PHASE 1：Instagram接続）

Instagramの投稿データを取得するには、Meta（Facebook・Instagramの運営会社）の
「開発者向けサイト」で、自分専用の接続キー（アクセストークン）を発行する必要があります。
少し手順が多いですが、1つずつ進めれば大丈夫です。分からなくなったら、
その時点の画面のスクリーンショットを見せてください。

### 事前に必要なもの

- InstagramアカウントBが **ビジネスアカウント または クリエイターアカウント** になっていること
  （個人アカウントのままだと接続できません。Instagramアプリの「設定」→「アカウントの種類とツール」で切り替えられます）
- そのInstagramアカウントに **連携したFacebookページ** があること
  （Instagramアプリの「プロフィールを編集」→「ページ」から作成・連携できます）

### 手順

1. ブラウザで [Meta for Developers](https://developers.facebook.com/) を開き、普段使っているFacebookアカウントでログインします
2. 右上の「マイアプリ」→「アプリを作成」を押します
3. アプリの種類は「その他」→「ビジネス」を選び、アプリ名を適当に入力して作成します（例：`ai-company-personal`）
4. 作成したアプリの管理画面で「製品を追加」から **「Instagramグラフ API」**（Instagram Graph API）を追加します
5. 左メニューの「ツール」→「Graph APIエクスプローラ」を開きます
6. 画面上部で、作成した自分のアプリを選択します
7. 「User or Page」で自分のFacebookユーザーを選び、「アクセス許可を追加」で以下を追加してから
   「アクセストークンを生成」を押します
   - `instagram_basic`
   - `instagram_manage_insights`
   - `pages_show_list`
   - `pages_read_engagement`
8. 発行された「アクセストークン」という文字列をコピーします（あとで `.env` に貼り付けます）
9. 同じGraph APIエクスプローラの入力欄に `me/accounts` と入力して実行し、
   自分のFacebookページの一覧から「id」の数字をコピーします（＝FacebookページID）
10. 続けて `<9で調べたページID>?fields=instagram_business_account` と入力して実行すると、
    `instagram_business_account` の中に `id` として数字が表示されます。
    これが **InstagramビジネスアカウントID** です

### `.env` ファイルに入力する

1. `ai-company/backend/.env.example` というファイルをコピーして、
   同じフォルダに `.env` という名前で保存します
2. `.env` を開いて、8番でコピーしたアクセストークンと、10番で調べたIDを入力します

```
INSTAGRAM_ACCESS_TOKEN=（8番でコピーした文字列）
INSTAGRAM_BUSINESS_ACCOUNT_ID=（10番で調べた数字）
```

3. 保存したら、「起動方法」の手順2でバックエンドを起動（すでに起動していた場合は
   一度 `Ctrl + C` で止めてから再度 `uvicorn app.main:app --port 8001`）します
4. ブラウザの画面で「Instagram投稿一覧」タブを開き、「今すぐ同期する」ボタンを押します
5. 投稿一覧が表示されれば接続成功です

### 補足（大事なポイント）

- ここで発行したアクセストークンは**有効期限が短い（数時間程度）テスト用**のものです。
  期限が切れると同期時にエラーが出るようになるので、その場合は手順5〜8をもう一度行い、
  `.env` の値を新しいトークンに書き換えてください。
  「毎回発行し直すのが大変」という場合は、次のPHASEで長期間有効なトークンへの
  切り替え手順を追記します。
- 動画（リール）と通常の投稿では取得できる数字の項目が異なります。取得できなかった
  項目は「—」と表示されます（勝手に0や空欄をでっちあげることはしません）。

## データの保存場所

Instagramのデータは `ai-company/backend/data.db` という1つのファイル（SQLiteデータベース）
に保存されます。このファイルは `.gitignore` で除外されているため、GitHubにはアップロードされません
（あなたのSNSデータが外部に公開される心配はありません）。

## バックアップ

`ai-company/backend/data.db` というファイルを、USBメモリやクラウドストレージなど
別の場所に定期的にコピーしておくとバックアップになります。

## アップデート方法（開発の進め方）

このシステムは一気に完成させず、以下の順番で段階的に作っていきます。

- PHASE 0：設計整理＋ダミーデータのUI試作品（今ここ）
- PHASE 1：Instagram接続を中心に実用レベルへ
- PHASE 2：note・lit.link・LINEを追加し、売上導線を分析できるように
- PHASE 3：TikTok・YouTubeを追加
- PHASE 4：AI社員会議・成功パターン学習・A/Bテストなど高度化

各PHASEの詳しい内容は [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md) にまとめています。

## 重要な安全ルール

- AIが勝手にnoteの内容やSNSのプロフィールを書き換えることはありません。常に「提案 → あなたの確認 → 実行」という流れです。
- APIキーやログイン情報などの秘密情報は、コードに直接書かず `ai-company/backend/.env` という専用ファイルで管理します。この`.env`ファイルは `.gitignore` の設定により、GitHubにはアップロードされません。
